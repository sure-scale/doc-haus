# Security

Do not include credentials, client documents, native databases or full-content
captures in public issues. Report a suspected vulnerability privately using
[GitHub security advisories](https://github.com/sure-scale/doc-haus/security/advisories/new).
Include a synthetic reproduction and affected revision.

The default setup is local. Keep engine and ingest on loopback. Detailed capture
is opt-in and can contain confidential content; store it privately and delete
it deliberately when no longer needed. Back up installation state before updates.
