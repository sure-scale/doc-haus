# Reusable templates

Open a Word document in a matter, choose **More actions → Create reusable
template**, and continue in Template Builder. The conversation receives a
captured copy of that document. It has no access to the rest of the matter or
its conversations. The original document remains unchanged.

Tell Template Builder the intended use, party position and jurisdiction. It can
ask focused questions, replace variable details with descriptive placeholders,
and prepare changes in a separate Word copy. The existing wording, numbering,
tables and formatting are retained. Negotiated terms need a deliberate decision
before they become a reusable firm position.

Choose **Review proposed template** to read the Word document and the actual
changes. Check any preparation notes and remaining client details, including
links and images, then enter a general template name and description. **Save to
library** publishes the reviewed version; **Keep editing** returns to the
conversation. Preparation alone does not add anything to the library.

Source-template conversations remain available on the Templates page. Reopening
one uses its captured source, even if the matter document has since changed.
To start from a newer document version, start a new conversion from the matter.

Resolve existing tracked changes and save a self-contained Word copy when a
document contains unsupported live fields, bound data or embedded content.
Comments and document properties are removed from the proposed template. These
steps do not certify the legal wording or remove client details from image
pixels; the review remains part of saving a template.

## Drafting from a template

To draft a document using a saved template, choose **Use** in the template
library and select the destination matter. That drafting conversation uses the
destination matter's instructions and sources.

From inside a matter, choose **Start from a template** under the upload area of
the Documents panel, pick a template, then choose **One document** or **Many
from a spreadsheet**. The matter is already known, so neither asks for it.

## Many documents from a spreadsheet

Choose **Fill from spreadsheet…** on a template, or **Many from a spreadsheet**
inside a matter, and add an Excel or CSV file with one row per document. Each
placeholder is matched to a column by its name; any that are not matched are
shown for you to pair or leave unfilled, and the matching is remembered for the
template. A column for an optional clause takes yes or no; a blank cell keeps
the template's default.

Step through the preview row by row and skip any row you do not want. In the
preview, each value filled in from the spreadsheet is highlighted; the saved
documents carry no highlight. A value the row leaves out can be typed in
beside the preview, for that row's document only; the spreadsheet is not
changed, and a typed value never replaces one the row already has. **Create**
saves one Word document per row into the matter, grouped in the Documents panel
under the template name and date. A row with a blank or unclear value is still
created, with its placeholder or clause marker left in the text and marked
**Needs input**; the mark clears once the document is edited to fill it. No
model is used: values are copied from the spreadsheet as written, so check them
before sending.
