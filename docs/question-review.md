# Reviewing workflow questions

Workflow questions could repeat facts already present in sources, arrive as
unrelated cards and lose their correction path once an answer was adopted.

Before a new factual question reaches the lawyer, one independent read-only
review can return exact source passages to the asking model for one
reconsideration. The model must still decide whether those passages settle its
uncertainty. These findings are untrusted evidence, never human answers,
permissions or approvals, and they are not written to the answer queue. Existing
human questions remain for the lawyer to answer.

Lean intake, drafting and amendment jobs share that pre-escalation path. Native
question calls, including builders, use the same review before a form exists.
The native adapter permits one evidence reconsideration per user turn and
reuses advice for an unchanged question. A failed review leaves the question
available with a visible explanation. Each recommendation carries checked
quotations and an attributed explanation of their applicability; this is advice,
not a certificate of legal support.

Native question history takes human authority only from actual user messages
and the native tool's structured successful answer arrays. Assistant-authored
question wording and recommendations are separate context, never instructions
attributed to the user. Saved advice is reused only for the same question scope
and current supporting quotations; changed inputs clear its recommendation while
retaining the unanswered card's offered option ids.

Related questions can share a topic while retaining their own ids, choices and
answers. The question card also lists earlier answers, including adopted advice,
and lets the lawyer send an explicit correction through the existing ordered
answer queue. Sending or viewing advice does not select or submit an answer.

Regression coverage exercises factual source feedback through the coordinator,
preservation of existing questions and judgment choices, bounded native
reconsideration, multi-select preservation, relevance requirements and the
untrusted evidence boundary. Browser coverage exercises grouped navigation and
queued/failed answer corrections. Validation is run after integration.
